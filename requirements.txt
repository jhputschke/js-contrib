# Python requirements for all js-contrib contribs (PyJetscape, FastHydro, Visualization,
# utils, example scripts, notebooks and tests):
#
#     pip install -r requirements.txt
#
# Not covered by pip:
#   - pyjetscape_core, the compiled bindings: built by X-SCAPE's CMake
#     (-DUSE_JS_CONTRIB=ON -DUSE_JS_PYJETSCAPE=ON) against the SAME Python as this env.
#     Install into the environment the core was built in (e.g. js_fno): a pip venv on the
#     system Python next to a conda-built core loads the system OpenSSL through torch and
#     then fails in conda's libcurl ("OPENSSL_3.2.0 not found"); jetscape.HAS_CORE is False.
#   - FnoHydro is C++ only (libtorch + ROOT, -DUSE_JS_FNO_HYDRO=ON); it has no Python deps.
#   - ROOT: conda-forge (`conda install -c conda-forge root`), only for USE_ROOT builds.
#   - torch below installs the default PyPI wheel (a CUDA build on Linux, MPS on macOS). For a
#     specific CUDA version or a CPU-only build install torch from the PyTorch index first,
#     e.g.  pip install torch --index-url https://download.pytorch.org/whl/cpu
#
# Minimal subsets: `pip install -e contribs/PyJetscape` (HDF5 I/O, prod scripts, notebooks;
# no torch) and `pip install -e "contribs/FastHydro[solver]"`.
