# Reference

Look-up pages. They are not meant to be read in order:

- **[Contribs and repositories](https://jhputschke.github.io/js-contrib/reference/contribs/index.md):** the four contribs, the repositories and images that make up a working setup, and the versions that belong together.
- **[Tools](https://jhputschke.github.io/js-contrib/reference/tools/index.md):** the command-line tools in `utils/` for planning, monitoring, inspecting and moving productions.
- **[AI assistants](https://jhputschke.github.io/js-contrib/reference/ai-assistants/index.md):** using Claude Code, other coding agents and chat assistants with js-contrib: the instruction file in the examples, `llms.txt`.
- **[X-SCAPE changes since 2.1](https://jhputschke.github.io/js-contrib/reference/changes/index.md):** the physics and technical bug fixes and the new features of X-SCAPE `contrib` relative to the 2.1 release, third-party packages included.
- **[Building this site](https://jhputschke.github.io/js-contrib/reference/site/index.md):** how to preview and change these pages.

The design notes, benchmark reports and production-readiness summaries that the pages refer to live in the repository's [`docs/`](https://github.com/jhputschke/js-contrib/tree/main/docs) folder.
