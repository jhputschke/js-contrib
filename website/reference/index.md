# Reference

Look-up pages. They are not meant to be read in order:

- **[Contribs and repositories](contribs.md):** the four contribs, the repositories and
  images that make up a working setup, and the versions that belong together.

- **[Building this site](site.md):** how to preview and change these pages.

The design notes, benchmark reports and production-readiness summaries that the pages refer to
live in the repository's
[`docs/`](https://github.com/jhputschke/js-contrib/tree/main/docs) folder.
